# 🚀 AutoPoster Telegram Bot

Асинхронный Telegram-бот на **aiogram 3.x** для автоматического ведения новостного канала в режиме **100% Автопилота**. Бот сам мониторит новостные ленты, делает ИИ-рерайт статей, накладывает водяные знаки на фотографии и выкладывает уникальный контент.

---

## Основные возможности

* **Автопостинг** — фоновая служба сканирует 3 крупных новостных источника с настраиваемым интервалом проверки (в минутах) напрямую из панели настроек бота.
* **ИИ-Рерайтинг** —  ИИ вырезает лишнюю воду и технические приписки новостных агентств, оставляя все самое главное и интересное
* **Защита от дубликатов** — асинхронное SQLite-хранилище запоминает опубликованные ссылки и исключает повторную отправку одних и тех же новостей.
* **Watermark** — автоматическое наложение аккуратного полупрозрачного водяного знака с вашим юзернеймом на все публикуемые фотографии.

## Быстрый старт

### 1. Подготовка окружения
```bash
git clone https://github.com/qwwqqqw/autopost-bot.git
cd autopost-bot

# Создание и активация виртуального окружения
python -m venv venv
venv\Scripts\activate # Windows
# source venv/bin/activate # Linux/macOS

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Настройка переменных `.env`
Создайте файл `.env` на основе примера `.env.example`:

```env
BOT_TOKEN=YOUR_BOT_TOKEN
ADMIN_ID=YOUR_ADMIN_ID
CHANNEL_ID=YOUR_CHANEL_ID
DEFAULT_WATERMARK=@YOU_WATERMARK
AI_API_KEY=YOUR_AI_API_KEY
```

### 3. Запуск бота
```bash
python main.py
```

## 📂 Структура проекта

```text
autopost_tg/
├── config.py              # Загрузка .env настроек и конфигурации
├── main.py                # Запуск бота и фоновых служб (планировщик + автопостинг)
├── database/
│   └── db.py              # Асинхронная работа с SQLite (настройки, опубликованное, очередь)
├── services/
│   ├── scheduler.py       # Служба фоновой публикации отложенных постов по таймеру
│   ├── autoposter.py      # Служба автоматического автопостинга новостей
│   ├── watermark.py       # Модуль наложения водяных знаков на изображения (Pillow)
│   ├── ai_rewrite.py      # Интеграция с Google Gemini API (gemini-3.1-flash-lite)
│   └── rss_parser.py      # Асинхронный парсинг RBC, RIA и Lenta через BeautifulSoup и httpx
├── handlers/
│   ├── common.py          # Панель управления, статус работы и настройки бота
│   ├── create_post.py     # Обработка создания отложенных постов
│   ├── scheduled.py       # Управление очередью отложенных публикаций
│   └── rss_feed.py        # Обработка ручного просмотра новостей (резервная)
├── keyboards/
│   ├── inline.py          # Инлайн-клавиатуры для настроек и автопостера
│   └── reply.py           # Главная клавиатура (Настройки / Status работы)
├── requirements.txt       # Список Python-зависимостей
├── .env.example           # Пример конфигурации
└── .gitignore             # Исключения для Git (секреты, БД, кэш)
```

## 🛠 Технологический стек

* **Python 3.10+**
* **aiogram 3.x** — асинхронный фреймворк для Telegram Bot API
* **Gemini API** — автоматический рерайт текста
* **Pillow** — обработка медиа и водяные знаки
* **BeautifulSoup4 & httpx** — асинхронный веб-скрейпинг новостей
* **aiosqlite** — асинхронная база данных
* **python-dotenv** — конфигурирование окружения
